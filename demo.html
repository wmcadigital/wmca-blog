🎯 WMCA Blog Web Component

Embed your Next.js blog anywhere with a custom HTML element

📰 Basic Demo

The simplest way to embed the WMCA blog:

Default Configuration

<wmca-blog app-url="http://localhost:3000" height="600px"> </wmca-blog>

🎮 Interactive Controls

Programmatically control the component:

const blog = document.querySelector('wmca-blog'); blog.reload(); blog.navigateToArticle('article-title'); blog.navigateToAuthor('Author Name');

📋 Configure Topics

Filter visible topics in the blog:

<wmca-blog app-url="http://localhost:3000" topics="Research and insights,Inclusive growth,Skills"> </wmca-blog>

Or via JavaScript:

const blog = document.querySelector('wmca-blog'); // Set topics blog.setTopics(['Research', 'Skills', 'Growth']); // Add topic blog.addTopic('NewTopic'); // Get current topics console.log(blog.getTopics()); // Remove topic blog.removeTopic('Research'); // Clear all topics blog.clearTopics();

💡 Quick Start Guide

1. Basic HTML Embedding

<wmca-blog app-url="https://blog.example.com"></wmca-blog> <script src="https://cdn.example.com/wmca-blog-component.js"></script>

2. With Configuration

<wmca-blog app-url="https://blog.example.com" height="900px" theme="light"> </wmca-blog> <script src="https://cdn.example.com/wmca-blog-component.js"></script>

3. In Umbraco Template (C#)

@* Your Umbraco .cshtml template *@ <wmca-blog app-url="@Model.BlogUrl" height="900px" theme="light"> </wmca-blog> <script src="@Model.CdnPath/wmca-blog-component.js"></script>

4. JavaScript Control

const blog = document.querySelector('wmca-blog'); // Reload blog.reload(); // Navigate to article blog.navigateToArticle('getting-started'); // Navigate to author blog.navigateToAuthor('Jane Smith');

Component Attributes

  • app-url - URL of your deployed Next.js app (required)
  • height - Container height (default: 800px)
  • theme - light or dark (default: light)
  • data-api-key - Umbraco API key (optional)
