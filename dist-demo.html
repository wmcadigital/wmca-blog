🚀 WMCA Blog - Dist Build Demo

This page demonstrates the optimized production build of the WMCA Blog application. The dist build includes all performance optimizations: dynamic imports, image optimization, ISR caching, and service worker support.

Build Type

Parcel-optimized production build

JavaScript Bundle

wmca-blog.*.js (~350 KB minified + gzipped)

Stylesheet

custom.*.css (~8 KB minified)

Cache Strategy

Content hashed for long-term caching

📂 Preview & Testing

How to Preview the Dist Build:

Option 1: Open Directly (Fastest)

Click the button below to open the dist build in a new window:

Option 2: Serve Dist Folder Directly (Recommended)

Serve the dist folder directly to properly handle relative asset paths:

cd dist
npx http-server
# Then visit: http://localhost:8080

Or with Python:

cd dist
python -m http.server 8000
# Then visit: http://localhost:8000

Option 3: Run Lighthouse Audit

Measure performance metrics with Lighthouse:

npm run lhci

✨ Build Optimizations

✓ Dynamic imports for non-critical components
✓ Responsive image optimization (AVIF/WebP)
✓ Incremental Static Regeneration (ISR)
✓ Service Worker caching
✓ SWC minification
✓ Production source maps
✓ 1-year HTTP caching headers
✓ API field filtering & pagination

📦 Usage Instructions

// Development
npm run next:dev

// Production build
npm run next:build
npm run next:start

// Parcel build (dist)
npm run build

// Build and run Lighthouse
npm run lhci
