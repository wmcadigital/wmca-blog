🎯 WMCA Blog - Next.js Embedded Demo

This page demonstrates how to embed the WMCA Blog Next.js application into an external HTML page (such as an Umbraco CMS template). The app is loaded via iframe and topics are passed via window.topics.

⚙️ Configuration

Note: The Next.js app must be running locally on port 3000 for this demo to work: npm run next:dev

📱 Next.js App Preview

http://localhost:3000/demo-topics

🔧 Umbraco CMS Integration Guide

How to embed this Next.js app in your Umbraco template:

Step 1: Set Topics in Your Umbraco View

@{ var topics = Model.Topics; // Your topics from Umbraco } <script> window.topics = @Html.Raw(Json.Encode(topics)); </script>

Step 2: Embed the App via iframe

<div id="blog-app"></div> <script> var appUrl = "http://localhost:3000/demo-topics"; // or your production URL document.getElementById('blog-app').innerHTML = '<iframe src="' + appUrl + '" style="width:100%; height:600px; border:none;"></iframe>'; </script>

Step 3: Or Embed Directly in HTML

<iframe src="http://localhost:3000/demo-topics" style="width:100%; height:600px; border:none; border-radius:8px;" title="WMCA Blog" ></iframe>

Topics Format

window.topics = [ "Research and insights", "Inclusive growth", "Skills, education and careers", "Life in the West Midlands", "People of the West Midlands" ];

💻 React Component Integration

Accessing Topics in BlogFilter.js

const topicOptions = useMemo(() => { // Get topics from window object (set by parent CMS or HTML page) const allowedTopics = typeof window !== 'undefined' && window.topics ? window.topics : blogCategories; return blogCategories .filter((category) => allowedTopics.includes(category)) .map((category) => ({ label: category.charAt(0).toUpperCase() + category.slice(1), value: category })); }, [blogCategories]);

Setting Topics in _document.js

import Document, { Html, Head, Main, NextScript } from 'next/document'; import Script from 'next/script'; class MyDocument extends Document { render() { return ( <Html lang="en-GB"> <Head> <Script strategy="beforeInteractive" dangerouslySetInnerHTML={{ __html: ` window.topics = [ "Research and insights", "Inclusive growth", "Skills, education and careers", "Life in the West Midlands", "People of the West Midlands" ]; `, }} /> </Head> <body> <Main /> <NextScript /> </body> </Html> ); } } export default MyDocument;
